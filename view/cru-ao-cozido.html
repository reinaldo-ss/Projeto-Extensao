💻 Módulo 3

Do Cru ao Cozido

Como um site nasce do zero? Neste módulo mostramos, passo a passo, a construção de uma página web — do HTML puro (o esqueleto) até o resultado visual final com CSS e interações com JavaScript.

1
🦴 HTML — O Esqueleto

Estrutura básica de qualquer página web

HTML (HyperText Markup Language) é a linguagem que define o conteúdo e a estrutura da página. Sem CSS, parece um documento de texto puro — mas é a fundação de tudo.

index.html — estrutura básica 
<!-- Toda página começa assim: -->
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8"/>
  <title>Tecnologia Verde</title>
</head>
<body>

  <h1>Tecnologia Verde 🌿</h1>
  <p>Como a TI pode ajudar o planeta.</p>
  <a href="sustentabilidade.html">
    Saiba mais
  </a>

</body>
</html>

☝️ Isso é um site funcional. Feio, mas funcional. Agora vem o CSS.

2
🎨 CSS — A Roupa

Transformando texto em design

CSS (Cascading Style Sheets) é responsável pela aparência visual: cores, fontes, espaçamentos, layout. É aqui que o site ganha identidade.

style.css — adicionando visual 
/* Variáveis de cor — fácil de manter */
:root {
  --verde: #2db870;
  --fundo: #0a0f0a;
  --texto: #e8f5e8;
}

/* Estilizando o corpo da página */
body {
  background: var(--fundo);
  color: var(--texto);
  font-family: 'DM Sans', sans-serif;
  padding: 40px;
}

/* Título grande e verde */
h1 {
  font-size: 3rem;
  color: var(--verde);
  font-weight: 800;
}
3
⚡ JavaScript — O Movimento

Dando vida e interatividade à página

JavaScript é a linguagem de programação do navegador. Com ela criamos menus, animações, formulários dinâmicos e muito mais.

script.js — interatividade 
// Mostra uma mensagem ao clicar no botão
const botao = document.querySelector("button");

botao.addEventListener("click", function() {

  // Muda o texto do botão
  botao.textContent = "Obrigado! ♻️";

  // Muda a cor de fundo
  botao.style.background = "#2db870";

  // Mostra um alerta
  alert("Você se comprometeu com o planeta! 🌱");

});
4
🍽️ Resultado Final — Cozido!

HTML + CSS + JS = Este site que você está vendo

O site que você está navegando agora foi criado exatamente assim: estrutura HTML, estilo CSS e interatividade com JavaScript. Tudo com tema de sustentabilidade — tecnologia e meio ambiente juntos.

🎯 Demonstração ao vivo: Durante a apresentação, o grupo mostrará este processo em tempo real — abrindo o Bloco de Notas, digitando o HTML, salvando como .html e abrindo no navegador. Em minutos, o público verá um site nascer do zero.
